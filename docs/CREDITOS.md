# Créditos

## Referências conceituais

As sete famílias de experiências foram discutidas a partir da transcrição enviada pelo usuário e do PDF “The GPT-6 Astra 3D Website Pack”, de Zubair Trabzada / AI Workshop. Vídeo de referência: https://www.youtube.com/watch?v=6U3k4H346Es.

O projeto não é afiliado ao autor do vídeo, à OpenAI ou ao Higgsfield. Não redistribui o PDF, seus prompts completos, retratos ou assets do autor. Não reproduz a afirmação de valor comercial do título.

## Produção original

- Código, geometria de portal, fita e caderno: produzidos neste repositório para Astra3D.
- Textos iniciais: exemplos originais para demonstrar personalização e leitura; não representam clientes ou resultados reais.
- `guia/assets/hero.png` e `capa/capa.png`: ilustração gerada localmente pelo fluxo INEMA, modelo flux2-klein, em 13/09/2026. A capa incorpora marca e título pelo template INEMA. É uma ilustração do conceito, não captura do app. Não se declara exclusividade sobre saída de geração.
- Template do guia: padrão projetos-landing-guia INEMA.

## Dependências

React e Three.js: MIT. Lucide: ISC. Manrope e DM Serif Display: SIL Open Font License (OFL); redistribuídas via Fontsource. As licenças das fontes estão em `public/licenses/`; o HTML exportado inclui os avisos do runtime e as fontes. O editor não busca recursos de fontes externamente; o guia padrão usa Google Fonts com fallback local do navegador.
